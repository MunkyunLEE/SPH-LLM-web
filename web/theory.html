1. 한눈에 보기

형상(OBJ·STL)을 올리고, 유체 블록·유입구·유출 영역을 화면이나 문장으로 지정한 뒤, 로컬 GPU에서 SPH 해석을 돌리고 결과를 3D 로 확인하는 개인용 도구입니다.

구성화면과 LLM 연결은 공통 모듈 Simweb-Core(FEM-LLM-web 에서 분리)를 씁니다. 계산 코어는 Taichi 로 작성해 같은 코드가 NVIDIA CUDA(WSL·Windows·Linux), Apple Metal(Mac), CPU 에서 돕니다. 수식은 DualSPHysics v5.4 를 기준으로 하고, 같은 장면을 원본 DualSPHysics 로도 돌려 결과를 비교합니다.
갈래내용
① 자유수면·대변형 유동댐 붕괴, 제트, 튀김, 슬로싱
② FSI강체 + 힌지, 이후 Bar-and-Hinge 오리가미에 유체력 전달
③ SWE-SPH지형 위 천수 방정식 입자, 범람 해석

3. 단위계

화면, 문장 지시, 케이스 파일, 결과 파일은 모두 FEM-LLM-web 과 같은 mm · tonne · s · N · MPa 입니다.

물리량값
물 밀도0.998e-9 tonne/mm³
공기 밀도1.204e-12 tonne/mm³
물 점성계수1.002e-9 MPa·s
중력9810 mm/s²
수심 1 m 정수압약 0.0098 MPa
GPU 단정밀도 주의float32 에서 (입자 질량 × 커널 기울기)² 같은 항이 1e-30 수준까지 작아집니다. 물은 여유가 있지만 공기나 굵은 입자(홍수 해석)에서는 float32 최소값 1.2e-38 에 닿아 조용히 0 이 될 수 있습니다. 그래서 계산 코어 안에서만 밀도를 ρ/ρ₀, 질량을 입자 부피 기준으로 정규화하고, 입출력에서 한 번만 변환합니다. 2단계 정수압 벤치마크에서 SI 계산과 결과가 같은지 매번 확인합니다.

4. SPH 원리

유체를 질량을 가진 입자로 나누고, 각 입자의 물리량을 주변 입자의 가중 평균으로 계산합니다. 격자가 없어서 자유수면이 깨지거나 물체가 크게 움직여도 다시 메쉬를 만들 필요가 없습니다.

4-1. 커널 보간

A(ra) ≈ Σb (mb/ρb) Ab W(rab, h)(1)

W Wendland 5차 커널 (DualSPHysics 기본), h 평활 길이, 지지 반경 2h

4-2. 지배방정식 (WCSPH, DualSPHysics v5.4 와 같은 식)

W(q) = (21 / 16πh³) (1 − q/2)⁴ (2q + 1), q = r/h, h = √3·dp, 지지 반경 2h(2) Wendland 커널
dρa/dt = Σb mb (va−vb)·∇aWab (ρa/ρb) + Da(3) 연속 방정식
Da = −Σb δ·2h·c0 [(ρb−ρa) − ρ0((1 + ρ0g zab/B)1/γ − 1)] / (rab² + η²) · (rab·∇aWab) mb/ρb(4) 밀도 확산 (Fourtakas, δ = 0.1)
dva/dt = −Σb mb [(Pa+Pb)/(ρaρb) + Πab] ∇aWab + g(5) 운동량
Πab = −α c0 h (rab·vab) / [(rab² + η²) ρ̄ab] (r·v < 0 일 때), η² = (0.1h)²(6) 인공 점성
층류: dva/dt += Σb mb 4ν (rab·∇aWab) / [(rab² + η²)(ρa+ρb)] vab(7) 층류 점성
P = B [(ρ/ρ0)γ − 1], B = c0²ρ0/γ, c0 = 20 √(g·Hswl), γ = 7(8) Tait 상태방정식

GPU 안에서는 ρ/ρ0, P/ρ0, 입자 부피 dp³ 만 다루고 ρ0 는 출력할 때만 곱합니다 (float32 아래넘침 방지). 위치는 CPU·CUDA 에서 float64, Metal 에서 float32 입니다.

4-3. 벽 경계 (DBC · mDBC)

DBC: 벽 안쪽 경계 입자도 연속 방정식으로 밀도가 오르내리며(ρ0 아래로는 내려가지 않음) 압력으로 유체를 밀어냅니다. 빠르지만 벽 바로 옆 두 층의 압력이 틀리고 벽 근처에 틈이 생깁니다.

mDBC: 각 경계 입자의 벽면 반대편 대칭점(고스트 점)에서 주변 유체 입자로 밀도와 기울기를 1차 정확도로 보간(4×4 보정 행렬, 행렬식 < 10⁻³ 이면 0차)해 경계 입자 밀도로 씁니다. 형상에서 법선을 자동으로 계산하고, 얇은 벽은 유체에서 가까운(젖는) 쪽 면을 고릅니다. 기본값입니다.

4-4. 시간적분

Symplectic: 예측 (Δt/2 로 위치·속도·밀도) → 이웃 재탐색 → 다시 힘 계산 → 보정 (밀도는 ρn+1 = ρn(2−ε)/(2+ε), ε = −(dρ/dt / ρ)Δt, 위치는 두 속도의 평균).

Δt = CFL · min( √(h/|a|max), h / (max(c0, 10|v|max) + h·max(r·v/(r²+η²))) ), CFL = 0.2(9)

밀도가 0.7ρ0 ~ 1.3ρ0 를 벗어나거나 해석 영역 밖으로 나간 입자는 제외합니다 (DualSPHysics 와 같음).

4-5. 결과 표시

출력 시점마다 입자 값을 정해진 격자(약 6만 점)에 Shepard 보간해 단면 색, 단면 벡터, 단면 유선, 와도(격자 중심차분), Q-criterion 등치면을 만듭니다. 프로브는 같은 보간으로 그 점의 속도·압력을 기록하고, 벽 하중은 유체 입자가 경계 입자에게 받는 압력·점성 힘의 반작용 합입니다.

5. 케이스 구성

항목내용
해석 영역이 박스를 벗어난 입자는 제거
물체올린 형상의 그룹별 역할 (벽 / 무시). 4단계부터 강체·힌지
유체 블록입자 간격 dx 격자로 채우는 초기 유체
유입구중심, 방향, 속력, 사각 또는 원형 단면, 유입 시간. 입자 ID 는 미리 확보해 두고 생성 시 켬
유출 영역들어간 입자를 제거하는 박스
정지 조건밀도 오차, 하중 등이 기준을 넘으면 일시정지

결과는 입자 ID 가 처음부터 끝까지 고정된 프레임 파일로 저장합니다 (meta.json + frames/*.npz). Rhino 용으로는 한 파일(npz)로 묶어 내보냅니다.

6. 검증 계획

층내용

2. 보존 검사질량 보존, 밀도 오차, 에너지 균형, 작용·반작용 (모든 해석에서 자동)
3. 벤치마크정수압, 댐 붕괴(Martin & Moyce, Koshizuka & Oka), 깔때기 배수, 부력, 쐐기 낙하, Stoker·Ritter·Thacker, 영국 환경청 홍수 벤치마크
4. 수렴·회귀해상도 3단계, CI 회귀 시험, 결과 이력 기록
5. 교차검증같은 장면을 원본 DualSPHysics 로 돌려 비교, 필요하면 SPlisHSPlasH·OpenFOAM

통과 기준은 벤치마크마다 정한 정합도 75% 이상입니다.

7. LLM 연결 방식

FEM-LLM-web 과 같습니다. 문장을 먼저 규칙 해석기가 읽고, 다 이해하면 바로 적용합니다. 못 알아들은 말이 남으면 그 문장만 LLM 으로 보냅니다. LLM 은 케이스를 직접 쓰지 않고 수정 지시(ops) JSON 만 내며, 서버가 검증한 뒤 적용합니다. 검증에 실패하면 오류를 붙여 한 번 더 요청합니다.

연결은 OpenAI 호환 엔드포인트 + API 키입니다. 화면 오른쪽 위에 넣거나 환경 변수 SPHWEB_LLM_URL, SPHWEB_LLM_MODEL, SPHWEB_LLM_KEY 로 지정합니다. 로컬 LLM 을 설치할 필요는 없습니다.
