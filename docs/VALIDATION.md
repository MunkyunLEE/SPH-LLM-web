# 검증 로드맵

통과 기준: 벤치마크마다 미리 정한 지표(예: 1 − 정규화 오차)로 정합도 75% 이상.

## 층 1. 단위 시험 (pytest, 매 수정마다)
- 커널 정규화, 기울기 일관성, GPU 이웃 탐색 = 전수 탐색
- 단위 일치: 같은 장면을 SI 와 mm·tonne 로 계산해 결과가 같은지
- 케이스 스키마, 수정 지시, 규칙 해석기 문장, STL 닫힘, OBJ 그룹·힌지 선

## 층 2. 보존·일관성 (모든 해석에서 자동, 화면에 표시)
- 질량: 유입 − 유출 = 내부 증가
- 비압축성: 평균 밀도 오차 1% 이하, 최대 3% 이하
- 에너지: 운동 + 위치 + 소산 = 외부 일
- 작용·반작용 (FSI), 힌지 구속 위반량

## 층 3. 해석해·실험 벤치마크

| 단계 | 벤치마크 | 비교 대상 |
|---|---|---|
| 2 | 정수압 탱크 | ρgh 분포, 벽 합력 |
| 2 | 3D 댐 붕괴 | 선단 위치·잔류 높이 (Martin & Moyce 1952, Koshizuka & Oka 1996 — DualSPHysics 예제에 실험값 포함) |
| 3 | 깔때기 배수 | 유량계수 Cd (2D 연습판 기준 재사용) |

| 4a | 떠 있는 상자 | 흘수·부력 |
| 4a | 쐐기 낙하 | 충격력 (Zhao & Faltinsen 1993) |

## 층 4. 수렴·회귀
- 해상도 3단계로 수렴 확인
- 저해상도 벤치마크를 CPU 로 CI 에서 매번 실행
- 결과(정확도, 입자 수, 시간, 장치)를 [`docs/benchmarks.md`](benchmarks.md) 에 이력으로 (2단계: 정수압·댐 붕괴 기록)

## 층 5. 교차검증 (정답지)
- **같은 장면을 원본 DualSPHysics v5.4 로 돌려 비교**. 같은 수식이니 결과가 거의 같아야 하고, 다르면 구현 오류
  - 사용자 WSL: DualSPHysics GPU
  - 개발 환경(클라우드): DualSPHysics CPU 판 빌드
- 필요하면 SPlisHSPlasH, OpenFOAM, LISFLOOD-FP / HEC-RAS 2D (SWE)
