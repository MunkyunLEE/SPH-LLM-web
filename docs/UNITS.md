# 단위계

화면, 문장 지시, 케이스 파일, 결과 파일은 모두 **mm · tonne · s · N · MPa** (FEM-LLM-web 과 같음).

| 물리량 | 단위 | 예 |
|---|---|---|
| 길이 | mm | 입자 간격 10 |
| 밀도 | tonne/mm³ | 물 0.998e-9, 공기 1.204e-12 |
| 동점성계수 μ | MPa·s | 물 1.002e-9 |
| 속도 | mm/s | 2 m/s = 2000 |
| 가속도 | mm/s² | 중력 9810 |
| 압력 | MPa | 수심 1 m ≈ 0.0098 |
| 힘 | N | |

문장 지시는 m, cm, m/s, kg/m³, Pa·s, kPa 등을 읽어서 바꿉니다 (`simweb.units`).

## GPU 단정밀도 정책

DFSPH·WCSPH 의 (입자 질량 × 커널 기울기)² 같은 항이 mm·tonne 단위에서 1e-30 수준까지 내려갑니다 (2026-11-20 계산: 입자 간격 10 mm 물 3e-30, 200 mm 물 8e-33). float32 최소 정상값은 1.2e-38 이라 물은 여유가 있지만, 공기(물의 1/830)나 굵은 입자(홍수)에서는 0 으로 사라질 수 있습니다. GPU 는 이런 값을 경고 없이 0 으로 버립니다.

그래서 계산 코어 안에서만:
- 밀도는 ρ/ρ₀ (1 근처), 질량 대신 입자 부피, 압력은 ρ₀ c₀² 로 나눈 값으로 계산
- 입출력에서 한 번만 mm·tonne 단위로 변환

2단계 정수압 벤치마크에 "SI 로 계산한 결과와 같은가" 시험을 넣어 매번 확인합니다.
